[02/12] 公式拆解

五个系数 · 一个风险分 把每一类风险归一到同一把尺子上

整套系统只用一个公式衡量"事件风险值"—— E = 100 × S × C × T × K × D。 五个系数分别回答五个问题：谁在说？说什么？多少人在说？说得多可信？传得多远？ 所有 D / C / B / A / S 分级、入库、红线兜底，都源自这一个数。

S
信源系数
0.90 → 2.00
谁在说。F预警 / 豆瓣 / 大小秘 / 社媒 四源任意组合，单源 → 四源齐发，权重逐级抬升。
C
类目场景
0.50 → 2.00
说什么。17 一级类目，204 二级场景库；未成年、关系型消费、红线合规权重最高。
T
热度系数
0.60 → 8.00
多少人在说。H0 热度折算 → 5 档跃迁；热搜化为 ×8，是 S 级危机的核心开关。
K
可信度
0.65 → 1.40
说得多可信。造谣 → 传言 → 部分事实 → 截图录屏 → 实锤/处罚，证据链层级。
D
扩散度
0.80 → 2.20
传得多远。停滞 → 平稳 → 升温 → 高涨 → 爆发（KOL/媒体/平台/热搜化）。

[05/12] K · 可信度 × D · 扩散度

证据链 × 传播曲线 事实多硬 · 火烧多远

K 衡量"事实硬度"——从只有情绪输出的造谣 (0.65) 一直到平台已经处罚的实锤 (1.4)； D 衡量"传播状态"——从停滞 (0.8) 跃迁到 KOL/媒体接手的爆发 (2.2)。 这两个系数一起决定了同一事件 30 倍以上的风险跨度。

[09/12] RNFP · 风险拆解入账机制

P → R · N · F · 三路归因拆分 峰值不退 · 只补差额 · 按贡献归因

事件升 P 之后, P 增量按"贡献分"拆给 R (传播)、N (投诉)、F (内部协同)—— 让事后归因不再争吵。三条规则确保账本稳定：峰值入账、只升不降、复燃只补差额。

N

F

E_live
实时风险值 · 可升可降 · 每次采集新数据后重算 · 用于看板当前态势。
E_peak
历史峰值 · 只升不降 · 用于入账与分级 · 避免日常指标跳变。
E_booked
已入账值 · 已计入 P/R/N/F 的分值 · 后续只补差额, 不自动扣回。
